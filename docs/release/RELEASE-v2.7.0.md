# v2.7.0 — 图表交互与可选悬停详情

发布日期：2026-10-16。发布渠道为 [GitHub Release](https://github.com/orxz/stock-alert-extension/releases/tag/v2.7.0)，提供扩展 ZIP 与 SHA-256 校验文件。

## 更新内容

- 悬停详情默认关闭，在「显示设置 → 悬停显示详情」开启，选择保存在本地；列表与卡片一致生效，点击仍可打开完整图表。
- 分时图使用完整交易时段、昨收对称价格轴与涨跌幅轴；日/周/月 K 线显示日期、完整历史 MA5/10/20 和独立成交量区。
- 图例和读数与画布分开，鼠标或方向键查看逐点数据，Esc 关闭；快速切换周期不会被迟到请求覆盖。
- 悬停图显示完整分钟点、最新价和起止时间，适配深浅主题、高分屏与价格掩码；浮层限制在 Popup 内并跟随滚动。
- 补齐历史开发分支的虚拟网格间距、看板重连/尺寸变化、设置焦点保持及菜单定位修复，已归档并清理该分支与工作目录。

## Review 验收

审查基线：`v2.6.0` → 本次发布代码。审查覆盖完整图表/悬停改动、展示偏好数据流、弹层生命周期、虚拟布局与发布门禁；并行专项审查核对图表及浮层组件。

发现并处理：

1. **P2，置信度 10/10：滚动后的卡片浮层停留旧位置。** 离线 Chromium 复现滚动 35px 后卡片移动而 fixed 浮层不动。修复为虚拟窗口完成 DOM 更新后集中定位当前 hover/focus 浮层。悬停优先项离开后再安排下一帧定位，覆盖隐藏焦点浮层恢复路径。新增 `hover-chart.spec.ts` 回归的两条路径均已验证红 → 绿。
2. **P1，置信度 10/10：CI 的关键测试被静默跳过。** GitHub Actions 日志显示 E2E 跳过 26 项、独立无障碍跳过 14 项、性能跳过 2 项。移除三个测试文件的 CI 条件跳过，让浏览器不可用或断言失败实际阻断发布。
3. **发布审计阻断，置信度 10/10：开发依赖漏洞。** `npm audit` 检出 `brace-expansion@5.0.9` 的高危拒绝服务漏洞；兼容补丁升级到 `5.0.12`，再次审计为 0 漏洞。仅涉及开发工具链，不新增扩展运行时依赖。依据：[维护者漏洞公告](https://github.com/advisories/GHSA-qhr7-859c-m2p7)。
4. **发布材料同步。** 更新版本号、功能文档、安装说明、显示设置文案与商店素材；历史版本快照保持归档。

审查未发现其他确认的发布阻断问题。服务器访问禁令持续生效，本次发布仅涉及本地验收与 GitHub 代码仓库发布。
