# 股票提醒助手 — 安装指南（本地版）

把这份指南和 ZIP 安装包一起发给朋友，照着做就行。

---

## 这是什么

一款 Chrome 浏览器扩展，看 A 股自选股行情用。支持分组管理、网格 / 列表双视图、涨跌幅排序，数据只存在你自己电脑上，不上传任何个人信息。

---

## 安装三步走

### 第一步：解压安装包

1. 找到我发给你的文件 `stock-alert-extension-v2.0.1.zip`（版本号可能不同，认准文件名开头的 `stock-alert-extension` 就行）
2. **右键 → 解压**（macOS 双击即可；Windows 右键选「全部解压缩」）
3. 解压后会得到一个文件夹，**记住这个文件夹的位置**（比如桌面）

> 注意：解压后的文件夹不要删，删了扩展就没了。建议放在一个固定的位置（比如「文档」文件夹），别放回收站旁边。

### 第二步：打开 Chrome 扩展管理页

1. 打开 Chrome 浏览器
2. 地址栏输入 `chrome://extensions` 然后回车
3. 页面**右上角**有一个「开发者模式」开关，**打开它**

> <!-- 截图占位：chrome://extensions 页面右上角开发者模式开关 -->

### 第三步：加载扩展

1. 开启开发者模式后，页面**左上角**会出现三个按钮，点「**加载已解压的扩展程序**」
2. 弹出选择框，选中你**第一步解压出来的文件夹**（选文件夹，不是选里面的文件，也不是选 zip）
3. 点「选择」

> <!-- 截图占位：左上角三个按钮，高亮「加载已解压的扩展程序」 -->

安装成功后，浏览器工具栏（右上角拼图图标里）会出现「股票提醒助手」的图标，点一下就能用了。

> 如果工具栏没看到图标，点右上角拼图图标 🧩，在列表里找到「股票提醒助手」，点旁边的图钉图标把它固定到工具栏。

## 常见问题

### Chrome 顶部弹出黄色警告条「禁用开发者模式扩展」

这是 Chrome 的正常安全提示，不是出问题了。点警告条右边的「**保留**」按钮即可，扩展照常使用。

如果手滑点了「放弃」，重新按上面三步加载一次就行。

### 怎么更新到新版本

本地版没有自动更新，出新版需要手动换包：

1. 找我要新的 ZIP 包，解压到一个新文件夹
2. 打开 `chrome://extensions`
3. 找到「股票提醒助手」卡片，点右下角的**刷新按钮**（圆形箭头图标）

> 如果点刷新没反应：先点「移除」删掉旧的，再按第三步「加载已解压的扩展程序」加载新文件夹。你的自选股数据不会丢。

### 我的自选股数据会丢吗

不会。所有数据存在你的浏览器本地，换版本、关电脑都不影响。只有「移除」扩展或清除浏览器数据才会清空。

### 和商店版有什么区别

功能完全一样。唯一区别是本地版没有自动更新，出新版要手动换包。

### 我用的是 Edge 浏览器

Edge 也支持，步骤几乎一样：

1. 解压 ZIP
2. 地址栏输入 `edge://extensions`
3. 打开左下角「开发人员模式」
4. 点「加载解压缩的扩展」

### 图标上的数字是什么

工具栏图标上会显示你自选股里排第一只的涨跌幅：红色涨、绿色跌、灰色表示行情暂时是缓存数据。鼠标放上去能看到前 5 只的情况。

## 隐私说明

- 你的自选股、分组、看板配置**只存在本地浏览器**，开发者不收集不上传
- 查行情时，只把股票代码发给行情服务商（东方财富主源 / 腾讯备源），不包含你的姓名、邮箱、浏览记录或分组名称
- 详细隐私政策见扩展内的「隐私权政策」页
