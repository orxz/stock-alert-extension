轻量级 A 股自选股分组与实时行情看板 Chrome 扩展。

【功能亮点】
• 大盘指数条：上证指数 / 深证成指 / 创业板指 / 科创50 常驻顶部，迷你走势图一眼看方向，
  点击即看完整分时与K线
• 多分组看板：1 个「全部」计算视图 + 最多 19 个自定义分组，可重排；一只股票可属多个分组
• 可信行情：东方财富主源 + 腾讯备源，实时 / 缓存 / 缺失三态明确标注，绝不生成模拟价格
• 分时与K线：点击任意股票/指数打开详情面板——分时图（价格线 + 均价 + 昨收基准 + 量能副图）、
  日K / 周K / 月K（蜡烛 + MA5/10/20 均线 + 量能副图），完整交易时段 / 日期刻度，鼠标或方向键查看逐点读数
• 可选悬停详情：默认关闭，在「显示设置」开启后，鼠标停在股票上展开 16 项行情 + 迷你分时走势——今开 / 最高 / 最低 / 昨收 /
  成交量 / 成交额 / 涨跌额 / 换手率 / 振幅 / 量比 / 市盈率 / 市净率 / 总市值 / 流通市值 / 涨停 / 跌停
• 涨停跌停：腾讯行情真值优先；缺失时按交易所规则推导（主板 ±10%、ST ±5%、
  创业板/科创板 ±20%、北交所 ±30%，四舍五入到分），涨跌幅幅度条按板块归一
• 双视图：网格卡片 / 数据列表，按涨跌幅、价格、成交额、自选时间排序，支持置顶与拖拽
• 显示设置：现价、涨跌幅、成交额、代码、状态可自由显隐并重排，选择本地持久化
• 智能搜索：代码 / 拼音 / 中文名称联想补全（含大盘指数），接口失败时自动降级本地搜索
• 实用细节：价格隐藏（投屏友好）、深浅双主题、盘中 10 秒 / 盘外 5 分钟自适应刷新

【覆盖市场】
沪深主板、科创板（688/689）、创业板（300/301/302）、北交所（920/830/430）及
上证/深证/北证主要大盘指数

【隐私优先】
自选股、分组与看板配置仅保存在本地浏览器，开发者不收集不上传。查询行情时仅把股票代码
发送给行情服务商，不包含姓名、邮箱、浏览记录或分组名称。仅申请 storage 与 alarms 两项权限。

【技术特性】
• TypeScript + 原生 ES Modules，零运行时第三方依赖
• 单一 StorageCoordinator 串行临界区，消除并发数据竞态
• 版本化 RPC（requestId + expectedRevision + 结构化错误）
• 虚拟滚动：按可见区域挂载股票行与卡片，支持 500 只自选股
• 完整键盘操作等价，WCAG 2.1 AA 无障碍

【说明】
本扩展当前不含价格提醒 / 到价通知功能，「股票提醒助手」为产品名称。
新股上市首日无常规涨跌停，当日涨跌停参考值为交易所规则推导。
