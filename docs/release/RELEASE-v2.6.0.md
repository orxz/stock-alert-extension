## 本次更新亮点

### 📈 大盘指数条

- 顶部常驻 **上证指数 / 深证成指 / 创业板指 / 科创50**（2×2 网格），每只显示名称 + 点位 + 涨跌幅 + 迷你走势图（面积渐变）
- **点击任意指数**打开详情面板看分时/K线；指数也可经搜索加入自选（`sh000xxx` / `sz399xxx` / `bj899xxx` 指数段）

### 📊 分时与K线（详情面板）

- 点击股票行 / 卡片打开详情面板：**分时图**（价格线 + 当日均价 + 昨收基准 + 量能副图）、**日K/周K/月K**（蜡烛 + MA5/10/20 + 量能副图 + 图例）
- **十字光标**悬浮读数、最新价标签、价格轴刻度；canvas 自绘零依赖，物理分辨率按容器实际尺寸 × DPR（不再拉伸发糊）
- hover 浮层另带**迷你分时走势**（按需拉取 + 缓存，失败静默降级）

### 🎯 涨跌停数据

- 修复「涨跌停一直缺失」：东财批量接口不返回该字段 + 备源只在主源缺失时才被调用 → 主源成功股永远 `--`
- **真值优先 + 交易所规则推导兜底**：主板 ±10%（ST ±5%）、创业/科创 ±20%、北交 ±30%，四舍五入到分（确定性公式，非模拟行情）
- 涨跌幅幅度条 / 涨停高亮按板块归一（创业板 19.95% 涨停正确高亮）

### 🧹 技术债清偿

- 迷你图绘制收敛到 `sparkline.ts` 单一真相（此前三处重复实现 + 四处 hexToRgba）
- canvas 测试 stub 收敛到共享 helper；canvas 尺寸守卫（十字光标不再重分配 backing store）

## 其他修复

- 指数条只剩名称（单行布局挤压）→ 2×2 网格
- 图表拉伸发糊 → 容器实际分辨率
- 指数条冷启动为空 → bootstrap 后立即刷新（首数据 ~0.5s）
- 详情面板 tablist 与分组标签 aria 冲突 → radio-group 语义
