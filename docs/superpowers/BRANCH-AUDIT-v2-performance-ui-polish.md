## 验证依据

- 7 项新组件回归在修改前失败，修改后通过；复现焦点丢失、弹层不跟随/不关闭、旧触发器状态残留、重连按钮失效和缺失尺寸观察。
- 网格浏览器回归在修改前测得首卡相对内容区偏移 8px（应为 0）；修复后校验完整序列位置与滚动总高度。
- 新增离线真实扩展测试，验证设置键盘操作、滚动中的菜单定位、虚拟化移除后关闭、底部边界。
- 最终验证命令：`CI=true RUN_A11Y=1 RUN_FAILURE=1 npm run ci`、`npm run test:performance`。
- 最终结果：1007 项单元/组件测试、359 项独立组件测试、25 项构建测试、91 项 E2E、14 项无障碍测试、2 项性能测试全部通过；类型、lint、架构和覆盖率门禁通过。
- 性能实测：500 只股票时 bootstrap p95 105.7ms、DOM 更新 p95 16.2ms，挂载列表 18 行/网格 12 张卡片。
- 首次全量运行曾遇到既有 `onInstalled triggers scheduler cycle` 的固定次数轮询超时；该测试文件独立复跑 9/9 通过，随后完整标准 CI 复跑通过，未修改后台业务或放宽测试断言。
