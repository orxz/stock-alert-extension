轻量级 A 股自选股分组与实时行情看板 Chrome 扩展。

【功能亮点】
• 多分组看板：最多 20 个自定义分组，拖拽排序；「全部」为计算视图
• 可信行情：东方财富主源 + 新浪备源，实时 / 缓存 / 缺失三态明确标注，绝不生成模拟价格
• 双视图：网格卡片 / 数据列表，按涨跌幅、价格、成交额、自选时间排序
• 排序联动角标：工具栏图标实时显示排序第一只股票的涨跌幅
• 智能搜索：代码 / 拼音 / 中文名称联想补全，API 失败时自动降级本地搜索
• 实用细节：自定义 12 列、价格隐藏（投屏友好）、盘中 10 秒 / 盘外 5 分钟自适应刷新

【覆盖市场】
沪深主板、科创板（688/689）、创业板（300/301）、北交所（920/830/430）

【隐私优先】
自选股、分组与看板配置仅保存在本地浏览器，开发者不收集不上传。查询行情时仅把股票代码发送给行情服务商，不包含姓名、邮箱、浏览记录或分组名称。

【技术特性（v2.0.0）】
• TypeScript + 原生 ES Modules，零运行时第三方依赖
• 单一 StorageCoordinator 串行临界区，消除并发数据竞态
• 版本化 RPC（requestId + expectedRevision + 结构化错误）
• 完整键盘操作等价，WCAG 2.1 AA 无障碍
