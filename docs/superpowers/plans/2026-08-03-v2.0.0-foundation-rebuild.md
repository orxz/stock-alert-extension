# v2.0.0 Foundation Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v1.3.0 global-script extension with a clean v2.0.0 TypeScript/ESM architecture that preserves user data and behavior while establishing durable protocol, storage, Service Worker, Popup, accessibility, testing, and release foundations.

**Architecture:** Build a native-ESM Manifest V3 extension whose shared Domain and Protocol layers have no DOM or Chrome dependencies. A single `StorageCoordinator` owns all local-storage consistency, the Service Worker owns remote data and scheduling, and the Popup uses an immutable Store plus semantic Commands and focused Light DOM Web Components. The formal `build/extension/` artifact is loadable from the first implementation task; v1 runtime compatibility code never enters v2.

**Tech Stack:** Chrome Extension Manifest V3, TypeScript 7, native ES2022 modules, Chrome Storage/Alarms/Action APIs, Node.js 22+, `node:test`, `tsx`, `happy-dom`, Playwright, `@axe-core/playwright`, ESLint with `typescript-eslint`, c8, fflate.

## Global Constraints

- Target version is exactly `2.0.0`; runtime source is TypeScript and emitted JavaScript is native ESM.
- Runtime third-party dependency count is `0`; do not add a framework, bundler, runtime state library, runtime validator, remote code, or dynamic code execution.
- TypeScript uses `strict: true`, `module: ES2022`, `target: ES2022`, `moduleResolution: Bundler`, `noEmitOnError: true`, `sourceMap: false`, and no declaration output in the extension artifact.
- Shared Domain/Protocol compilation sees `ES2022` only; Popup sees `DOM`; Background/Chrome Infrastructure sees `WebWorker` plus Chrome types.
- Every runtime relative import uses a `.js` suffix. Bare imports, path aliases, import cycles, missing emitted targets, and reverse layer imports fail CI.
- Manifest permissions remain exactly `storage` and `alarms`; host permissions remain exactly `hq.sinajs.cn`, `push2.eastmoney.com`, and `searchapi.eastmoney.com` HTTPS patterns.
- Persistent schema remains v2: `groups`, `watchlist`, `boardConfig`, and `quoteCache:<code>`; `g_all` is computed and is never stored in stock memberships.
- All local-storage business reads and writes go through one `StorageCoordinator`; no repository or adapter owns a second write queue.
- `userDataRevision` is the SHA-256 digest of canonicalized `groups + watchlist + boardConfig`; it is never stored as a separate key.
- Every RPC mutation is an idempotent final-state command with `expectedRevision`; there are no toggle mutations, server-generated entity IDs, v1 actions, or dual-protocol branches.
- Service Worker listeners register synchronously. Async handlers wait on a shared retryable initialization barrier, and every activation verifies the quote Alarm.
- Quote rules remain: `price > 0`, Eastmoney primary, Sina fallback, 50 symbols per batch, 4-second provider timeout, 8-second overall deadline, concurrency `2`, fresh cache `<30s`, cached cache `30s–7d`, expired cache deletion, and backoff `30s → 2m → 5m` in `chrome.storage.session`.
- Missing quotes never use generated or substituted prices. Empty watchlists do not access providers or advance backoff.
- `domain.boardConfig` is the only persistent UI-preference truth; Popup view state contains only session state.
- Web Components are admitted only for real lifecycle, focus, or stable-node-identity needs. Do not create `BaseComponent`, `BaseRepository`, `BaseService`, or one-method forwarding wrappers.
- All component listeners use per-connection `AbortController` cleanup; keyed updates preserve node identity, focus, and scroll.
- Native controls, keyboard equivalence, focus restoration, 44×44px targets, reduced motion, WCAG 2.1 AA contrast, and zero axe critical/serious findings are release requirements.
- Coverage gates are 90% lines/statements/functions and 85% branches for all `src/**`; Domain, Protocol, Storage, and Reducer require 95% lines/statements/functions and 90% branches.
- Formal E2E loads only `build/extension/`. Release ZIP is deterministic, excludes source/tests/maps/docs, warns above 200 KB, and fails above 500 KB.
- v1.3.0 ZIP, SHA, tag, and test-only reference reader are retained for rollback verification; no v1 runtime file or compatibility adapter is shipped in v2.

```js
const NOW = Date.parse('2026-08-03T01:30:00.000Z');
const envelope = (payload) => ({ contractVersion: 1, sourceVersion: '1.3.0', capturedAt: NOW, payload });
const canonicalize = (value) => Array.isArray(value)
  ? value.map(canonicalize)
  : value && typeof value === 'object'
    ? Object.fromEntries(Object.keys(value).sort().map((key) => [key, canonicalize(value[key])]))
    : value;
const stable = (value) => `${JSON.stringify(canonicalize(value), null, 2)}\n`;

export async function capture(output = new URL('../tests/fixtures/v1.3/', import.meta.url)) {
  await mkdir(output, { recursive: true });
  const cases = createFixedCases(NOW);
  for (const [name, raw] of Object.entries(cases.storage)) {
    const area = createMemoryArea(raw);
    const data = await createStorage({ area, clock: () => NOW }).loadAll();
    await writeFile(new URL(`storage-${name}.json`, output), stable(envelope({ input: raw, output: data })));
  }
  await writeFile(new URL('quote-snapshot.json', output), stable(envelope(cases.quoteSnapshot)));
  await writeFile(new URL('formatting.json', output), stable(envelope(cases.formatting)));
}

function createMemoryArea(seed) {
  let state = structuredClone(seed);
  return {
    async get(keys = null) {
      if (keys === null) return structuredClone(state);
      const selected = {};
      for (const key of Array.isArray(keys) ? keys : [keys]) {
        if (Object.hasOwn(state, key)) selected[key] = structuredClone(state[key]);
      }
      return selected;
    },
    async set(patch) { state = { ...state, ...structuredClone(patch) }; },
    async remove(keys) { for (const key of Array.isArray(keys) ? keys : [keys]) delete state[key]; }
  };
}
```

```js
// tests/fixtures/v1.3/reference-reader.mjs
export function readWithV13Rules(raw, now) {
  const groups = sanitizeGroups(raw.groups, now);
  const valid = new Set(groups.map((group) => group.groupId));
  const watchlist = sanitizeStocks(raw.watchlist, valid, now);
  const boardConfig = raw.boardConfig && typeof raw.boardConfig === 'object'
    ? structuredClone(raw.boardConfig)
    : {};
  return { schemaVersion: 2, groups, watchlist, boardConfig };
}

function sanitizeGroups(value, now) {
  const input = Array.isArray(value) ? value.filter((item) => item && typeof item.groupId === 'string') : [];
  const custom = [];
  const seen = new Set(['g_all']);
  for (const item of input) {
    if (item.groupId === 'g_all' || seen.has(item.groupId) || custom.length === 19) continue;
    seen.add(item.groupId);
    custom.push({ ...item, order: custom.length + 1, isDefault: false, createdAt: item.createdAt ?? now, updatedAt: item.updatedAt ?? now });
  }
  const existingAll = input.find((item) => item.groupId === 'g_all');
  return [{ ...existingAll, groupId: 'g_all', name: existingAll?.name || '全部', order: 0, isDefault: true, createdAt: existingAll?.createdAt ?? now, updatedAt: existingAll?.updatedAt ?? now }, ...custom];
}

function sanitizeStocks(value, validGroupIds, now) {
  const byCode = new Map();
  for (const item of Array.isArray(value) ? value : []) {
    const code = normalizeReferenceCode(item?.code);
    if (!code) continue;
    const next = {
      code,
      name: typeof item.name === 'string' ? item.name : '',
      groupIds: [...new Set((Array.isArray(item.groupIds) ? item.groupIds : []).filter((id) => id !== 'g_all' && validGroupIds.has(id)))],
      manualOrder: item.manualOrder && typeof item.manualOrder === 'object' ? { ...item.manualOrder } : {},
      pinned: item.pinned && typeof item.pinned === 'object' ? { ...item.pinned } : {},
      addedAt: Number.isFinite(item.addedAt) ? item.addedAt : now
    };
    const current = byCode.get(code);
    if (!current) byCode.set(code, next);
    else {
      current.groupIds = [...new Set([...current.groupIds, ...next.groupIds])];
      current.manualOrder = { ...next.manualOrder, ...current.manualOrder };
      current.pinned = { ...next.pinned, ...current.pinned };
      current.addedAt = Math.min(current.addedAt, next.addedAt);
      if (!current.name) current.name = next.name;
    }
  }
  return [...byCode.values()];
}

function normalizeReferenceCode(input) {
  const match = /^(?:(sh|sz|bj))?(\d{6})$/.exec(String(input ?? '').trim().toLowerCase());
  if (!match) return null;
  const market = /^(600|601|603|605|688|689)/.test(match[2]) ? 'sh'
    : /^(000|001|002|003|300|301)/.test(match[2]) ? 'sz'
      : /^(920|8|4)/.test(match[2]) ? 'bj' : null;
  return market && (!match[1] || match[1] === market) ? `${market}${match[2]}` : null;
}
```

- [ ] **Step 5: Implement the clean formal build**

```js
// scripts/build-extension.mjs
import { cp, lstat, mkdir, rm } from 'node:fs/promises';
import { execFile } from 'node:child_process';
import { fileURLToPath } from 'node:url';
import { join, resolve } from 'node:path';
import { promisify } from 'node:util';
const exec = promisify(execFile);

async function assertDedicatedBuildPath(root, buildRoot) {
  const rootPath = resolve(fileURLToPath(root));
  const buildPath = resolve(fileURLToPath(buildRoot));
  if (buildPath !== join(rootPath, 'build') || buildPath === rootPath || buildPath === resolve('/')) {
    throw new Error(`refusing unsafe build path: ${buildPath}`);
  }
  try {
    if ((await lstat(buildPath)).isSymbolicLink()) throw new Error(`refusing symlink build path: ${buildPath}`);
  } catch (error) {
    if (error?.code !== 'ENOENT') throw error;
  }
}

export async function buildExtension(root = new URL('../', import.meta.url)) {
  const buildRoot = new URL('build/', root);
  const build = new URL('build/extension/', root);
  await assertDedicatedBuildPath(root, buildRoot);
  await rm(buildRoot, { recursive: true, force: true });
  await mkdir(build, { recursive: true });
  await cp(new URL('extension/', root), build, { recursive: true });
  await exec('node_modules/.bin/tsc', ['--build', 'tsconfig.json'], { cwd: new URL('.', root) });
  return build;
}
```

`assertDedicatedBuildPath()` resolves both URLs and accepts only `<repository>/build/`; it rejects the repository root, filesystem root, symbolic-link escape, or any other target.

- [ ] **Step 4: Implement stock normalization and quote validity**

```ts
export function normalizeStockCode(input: unknown): StockCode | null {
  const value = String(input ?? '').trim().toLowerCase();
  const match = /^(?:(sh|sz|bj))?(\d{6})$/.exec(value);
  if (!match) return null;
  const [, explicit, digits] = match;
  const inferred = inferMarket(digits);
  if (!inferred || (explicit && explicit !== inferred)) return null;
  return `${inferred}${digits}` as StockCode;
}

function inferMarket(digits: string): 'sh' | 'sz' | 'bj' | null {
  if (/^(600|601|603|605|688|689)/.test(digits)) return 'sh';
  if (/^(000|001|002|003|300|301)/.test(digits)) return 'sz';
  if (/^(4|8|920)/.test(digits)) return 'bj';
  return null;
}

export function isUsableQuote(quote: Quote | null): quote is Quote {
  return quote !== null && Number.isFinite(quote.price) && quote.price > 0;
}

export function snapshotFromCache(
  cache: Readonly<Record<StockCode, QuoteCacheEntry>>,
  codes: readonly StockCode[],
  now: number,
  freshnessMs = 30_000
): QuoteSnapshot {
  const results = {} as Record<StockCode, QuoteResult>;
  const counts = { fresh: 0, cached: 0, missing: 0 };
  for (const code of codes) {
    const entry = cache[code];
    const age = entry ? Math.max(0, now - entry.fetchedAt) : Number.POSITIVE_INFINITY;
    const status = entry && isUsableQuote(entry.quote) && age <= 604_800_000
      ? age < freshnessMs ? 'fresh' : 'cached'
      : 'missing';
    counts[status] += 1;
    results[code] = status === 'missing'
      ? { code, status, source: 'none', provider: null, fetchedAt: null, quote: null, error: 'unavailable' }
      : { code, status, source: status === 'fresh' ? entry.provider : 'cache', provider: entry.provider, fetchedAt: entry.fetchedAt, quote: entry.quote, error: null };
  }
  return { results, counts, attemptedAt: now, succeededAt: null, generation: 0 };
}
```

`snapshotFromCache()` marks valid entries younger than `freshnessMs` fresh, valid entries up to seven days cached, and every absent/invalid/older entry missing. Port all v1.3 supported-prefix cases and zero-price cases exactly; do not add another market.

```ts
export async function computeUserDataRevision(data: UserData): Promise<UserDataRevision> {
  const canonical = canonicalJson({
    groups: data.groups,
    watchlist: data.watchlist,
    boardConfig: data.boardConfig
  });
  const bytes = new TextEncoder().encode(canonical);
  const digest = await crypto.subtle.digest('SHA-256', bytes);
  return `sha256:${[...new Uint8Array(digest)].map((byte) => byte.toString(16).padStart(2, '0')).join('')}` as UserDataRevision;
}

function canonicalJson(value: unknown): string {
  const normalize = (input: unknown): unknown => Array.isArray(input)
    ? input.map(normalize)
    : input !== null && typeof input === 'object'
      ? Object.fromEntries(Object.keys(input).sort().map((key) => [key, normalize((input as Record<string, unknown>)[key])]))
      : input;
  return JSON.stringify(normalize(value));
}
```

`canonicalJson()` sorts object keys recursively and preserves array order. Tests assert key-insertion order does not change the digest, while stock/group/config content changes do.

```ts
export function createInitializationBarrier<T>(initialize: () => Promise<T>) {
  let state: 'idle' | 'running' | 'ready' = 'idle';
  let value: T | undefined;
  let running: Promise<T> | undefined;
  return {
    get(): Promise<T> {
      if (state === 'ready') return Promise.resolve(value as T);
      if (state === 'running') return running as Promise<T>;
      state = 'running';
      running = initialize().then(
        (next) => { value = next; state = 'ready'; return next; },
        (error) => { running = undefined; state = 'idle'; throw error; }
      );
      return running;
    }
  };
}
```

- [ ] **Step 5: Implement reconcile-before-retry**

```ts
export class MutationReconciler {
  constructor(private readonly rpc: RpcClient, private readonly store: Store) {}

  async execute<M extends MutationMethod>(method: M, payload: RpcPayload<M>, key: string): Promise<void> {
    this.store.dispatch({ type: 'mutation/pending', key });
    try {
      const result = await this.rpc.call(method, payload);
      this.store.dispatch({ type: 'mutation/confirmed', key, result });
    } catch (error) {
      if (!(error instanceof RpcUncertainError)) return this.fail(key, error);
      this.store.dispatch({ type: 'mutation/uncertain', key });
      const bootstrap = await this.rpc.call('app:bootstrap', {});
      this.store.dispatch({ type: 'bootstrap/confirmed', result: bootstrap });
      if (desiredState[method](payload, bootstrap.userData)) return this.confirmFromBootstrap(key);
      const retried = await this.rpc.call(method, { ...payload, expectedRevision: bootstrap.revision });
      this.store.dispatch({ type: 'mutation/confirmed', key, result: retried });
    }
  }

  private fail(key: string, error: unknown): void {
    this.store.dispatch({ type: 'mutation/failed', key, error: toSafeClientError(error) });
  }

  private confirmFromBootstrap(key: string): void {
    this.store.dispatch({ type: 'mutation/reconciled', key });
  }
}
```

`mutation/reconciled` clears the mutation async entry without modifying Domain data because the preceding `bootstrap/confirmed` already installed the authoritative snapshot. `toSafeClientError()` maps typed RPC errors to the client-safe `{ code, message, retryable }` shape. Allow only one automatic retry. A second uncertainty remains visible and requires an explicit user retry after another bootstrap. A `CONFLICT` always resyncs and reports that newer data was loaded; it does not overwrite the newer state.
